# 台股籌碼開放資料每日累積

每個交易日自動收集台股籌碼與日 K，累積成可供回測的長序列。

**為什麼需要累積**：官方 OpenAPI 只提供**當日快照**，不提供歷史查詢
（TWSE 143 個、TPEx 225 個端點，經逐一檢查**沒有任何一個**接受日期參數）。
沒有人每天存下來，那一天的資料就永遠取不回來了。

## 資料來源與授權

| 來源 | 端點 |
|---|---|
| 臺灣證券交易所 OpenAPI | `openapi.twse.com.tw` |
| 證券櫃檯買賣中心 OpenAPI | `www.tpex.org.tw/openapi` |

兩者皆為**政府資料開放授權**（<https://data.gov.tw/license>）。

> 資料來源：臺灣證券交易所、證券櫃檯買賣中心

本 repo **只收開放授權來源**。每個資料檔都標記 `"license": "open"`，
CI 在 commit 前會逐檔驗證，非開放授權的資料無法進入。

## 收集內容

| 種類 | 說明 | 約略檔數 |
|---|---|---|
| `price_twse` / `price_tpex` | 日 K（開高低收、成交股數） | 1,359 / 974 |
| `margin_twse` / `margin_tpex` | 融資融券餘額（張） | 1,287 / 913 |
| `inst_tpex` | 上櫃三大法人買賣超（股） | 898 |

**上市三大法人不在此列**：TWSE OpenAPI 沒有逐檔法人資料，
只有類股別與前 20 名彙總表——那是不同的東西，不會拿來湊。

## 檔案格式

每個交易日一個檔，涵蓋全市場：

```
data/official/<種類>/YYYY-MM-DD.json
```

```json
{
  "schema": 1,
  "kind": "margin_twse",
  "license": "open",
  "trade_date": "2026-07-27",
  "source": "twse_openapi_mi_margn",
  "fields": ["margin_balance_lots", "short_balance_lots"],
  "value_type": "int",
  "revision": 1,
  "checksum": "…",
  "previous_checksum": null,
  "rows": { "2330": [31915, 67], "…": [] }
}
```

- `fields` 決定 `rows` 陣列的欄位順序。**讀取時請以檔案內的 `fields` 為準**，
  不要寫死——日後欄位若有增修，舊檔才不會被錯位解讀。
- 價格為**字串**（避免浮點誤差），數量為整數。
- `revision` > 1 表示該日資料曾被上游更正；`previous_checksum` 保留稽核鏈。

## 幾個資料上的坑（都已處理，但值得知道）

1. **`MI_MARGN` 沒有日期欄，而且會落後。** 實測 2026-07-27 當天它提供的是 07-24 的資料。
   若照直覺標成「今天」，全上市的融資券都會掛錯日期——不會報錯，就是安靜地全錯。
   本專案的日期取自同站 `STOCK_DAY_ALL` 的 `Date` 欄（同發布週期，實測吻合），
   是**取得**的而非假定的。

2. **空字串代表 0。** TWSE 以 `""` 表示數值 0；實測 1,287 列中有 969 列至少一欄為空。
   若當成缺值剔除，等於安靜丟掉四分之三的市場。

3. **`0.00` 不是價格，是「當日無成交」。** 實測上市 13 檔、上櫃 39 檔。
   存成 0 會讓回測算出 −100% 的假虧損，因此這類列**不予收錄**——
   OHLC 序列裡「沒成交」的正確表示是沒有這根 K。

4. **官方欄名有多餘空白與拼字**，例如
   `ForeignInvestorsInclude MainlandAreaInvestors-Difference`（中間有空格）、
   `ShortConvering`（少一個 r）。這些是取值的關鍵，「訂正」就會取不到值。

## 資料驗證

每一列都要通過恆等式才會被收錄，過不了的整列剔除（不靜默修正）：

- 融資：`今日餘額 = 前日 + 買進 − 賣出 − 現金償還`
- 融券：`今日餘額 = 前日 + 賣出 − 買進 − 現券償還`
- 法人：`含外資自營商 = 不含 + 外資自營商`、`三類之和 = 合計`

實測全市場零違反。

## 自己跑

```bash
python harvest.py              # 收集今天，寫入 ./data
python harvest.py --status     # 看累積狀況
python harvest.py --dir /path  # 指定輸出目錄
```

需要 Python 3.11+，**不需要安裝任何套件**（純標準庫），也不需要任何金鑰。
